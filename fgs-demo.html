LockHour Pro – Foreground service demo

This video is a real screen recording of LockHour Pro for Android (release build, Android 15 emulator). It shows why the app uses a foreground service of type specialUse (FOREGROUND_SERVICE_SPECIAL_USE).

Download / open the video file (MP4, H.264)

What the foreground service does

While a focus session that the user started is running, UsageMonitorService checks which app is in the foreground (using Usage Access that the user granted) and, if it is an app the user chose to block, shows LockHour's blocking screen. Its ongoing notification shows the time remaining. The service stops and the notification is removed as soon as the session ends or is ended by the user. No data leaves the device.

Steps shown in the video

  1. Open LockHour Pro.
  2. Choose an app to block (Clock in this demo) and save.
  3. Start a focus session – the foreground service starts.
  4. The ongoing notification in the notification shade shows the time left.
  5. Opening the blocked app shows the LockHour blocking screen.
  6. "Keep Focusing" returns to LockHour.
  7. End the session – the service stops and the notification is removed.
